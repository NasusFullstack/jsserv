# jsserv

여러 기능을 함께 얹는 서버입니다. **무엇 하나의 전용이 아닙니다.**

기능마다 자기 경로를 가지고 들어옵니다. 루트(`/`)는 브라우저로 열면 포트폴리오 첫 화면, 프로그램이 물으면
지금 무엇이 올라와 있는지(JSON)를 알려줍니다.

| 주소 | 하는 일 |
|---|---|
| `GET /` | 브라우저: 포트폴리오 첫 화면 · 프로그램: 무엇이 올라와 있는지 + 각 기능의 버전 |
| `GET /health` | 살아있는지 |
| `/`, `/w/…`, `/p/…`, `/dl/…`, `/admin`, `/api/…` | 포트폴리오 사이트 — 작품·방문 통계·관리 |
| `/battle/…` | 춥채팅 배틀크루저 전투 중계 |
| `/files/…` | 춥채팅 파일·사진 올리기 |
| `/logs/…` | 춥채팅 채팅 기록 하루치 |
| `/profiles/…` | 춥채팅 참여자 프로필(아이콘) |
| `/game/…` | 웹 게임 올려두기 — 게임 파일은 저장소 밖, 열쇠로 직접 올림 |
| `/chat/…` | 춥채팅 서버 채팅 — IRC 없이 (**지금은 꺼 둠**, `app.py` 참고) |

## 기능 추가하기

`features/` 에 파일 하나를 만들고 `app.py`의 목록에 한 줄 추가하면 끝입니다.
기능 파일이 갖춰야 할 것은 `features/__init__.py`에 적어뒀습니다.
**기능끼리는 서로를 모릅니다** — 하나를 고칠 때 다른 것을 읽을 필요가 없어야 합니다.

## site — 포트폴리오 사이트

만든 작품(게임·앱·도구…)을 모아 보여주는 사이트. 방문 수를 세고, 주인은 `/admin` 에서 열쇠로 관리한다.

- **첫 화면** `/` — 이름·소개, 작품 카드(종류별 필터), 서버 상태(가동 시간·응답 시간), 방문 수(14일), 연락처.
  작품을 누르면 자세히(주소가 `/w/<작품>` 으로 바뀌어 링크를 보낼 수 있고, 미리보기에 그 작품 제목·그림이 뜬다)
- **관리** `/admin` — 열쇠를 넣으면 이 탭에서만 기억. 대시보드(30일 통계·들어온 곳·디스크),
  작품 추가·수정·숨기기·삭제, 대표 그림·스크린샷·다운로드 파일·웹 빌드(zip) 올리기, 사이트 이름·소개 고치기
- **웹 빌드** — `index.html` 이 든 zip 을 올리면 `/p/<작품>/` 에서 바로 플레이 (Godot·Unity 웹 내보내기, HTML5 게임)
- **GitHub 릴리스** — 작품에 `주인/저장소` 를 적으면 최신 릴리스의 버전·파일이 다운로드 버튼으로 자동으로 나온다(30분마다 확인)
- **방문 통계** — 하루 한 사람 한 번씩 센다. IP 는 저장하지 않는다(날마다 바뀌는 지문만, 이틀 뒤 삭제). 검색 로봇은 안 센다

```
GET  /api/overview                 첫 화면이 그리는 모든 것
GET  /dl/<작품>                    다운로드 (올린 파일)   /dl/<작품>/a/<파일> GitHub 릴리스로 넘겨줌
(열쇠 X-Admin-Key)  GET /api/admin/overview · PUT /api/admin/settings · PUT|DELETE /api/admin/works/<작품>
                    POST /api/admin/works/<작품>/cover|shots|download|build
```

열쇠는 따로 정하지 않으면 게임 올리기 열쇠와 같다(지문만 코드에 있음). 나누려면 환경 변수 `JSSERV_ADMIN_TOKEN_SHA256`.
데이터는 `/data/jsserv/site`(작품 목록·그림·파일·통계), 화면 파일은 저장소의 `web/`.
코드는 층으로 나눴다 — 자세한 것은 `features/site/__init__.py`.

```
features/site/  config(설정) → store(저장) · stats(통계) · auth(열쇠) · releases(GitHub) → service(규칙) → routes(주소)
web/static/css/ tokens → base → layers(배경 레이어) → components → home / admin → motion
web/static/js/  core(통신·DOM·형식·그래프) · fx(효과 하나당 파일 하나) · home / admin(칸 하나당 파일 하나)
```

## chat — 서버 채팅 (IRC 없이)

[춥채팅](https://github.com/NasusFullstack/chat)은 원래 IRC 서버에 붙습니다. IRC는 남의
규약이라 못 하는 것이 많았고, 전부 우회해서 겨우 되게 만들어 뒀는데 그 우회 하나하나가
사고의 원인이기도 했습니다.

| IRC에서 | 여기서 |
|---|---|
| 한 줄 512바이트 — 아이콘을 300자씩 쪼개 보냄(조각이 빠지면 안 뜸) | 그냥 보냅니다 |
| 한글 닉네임을 서버가 거절 | 됩니다 |
| 아이콘·표시이름을 CTCP로 몰래 주고받음 | 서버가 들고 있습니다 |
| "무슨 앱 쓰나"를 물어보면 폭주로 보고 끊음 | 서버가 압니다 |
| 지난 기록이 없어 **각자** 올리고 서버가 중복 제거 | 서버에 원본이 있습니다 |
| 귓속말은 기록도 알림도 안 됨 | 됩니다 |

**IRC를 없애지는 않습니다.** 둘을 따로 쓸 수 있게 두고 사람이 고릅니다.

```
POST /chat/register   계정 만들기 (비밀번호는 해시로만 보관)
WS   /chat/ws         채팅
```

오가는 줄은 전부 `{"cmd": ...}` / `{"type": ...}` 꼴의 JSON 한 줄입니다.
**표에 없는 명령은 조용히 버립니다** — 구버전 클라이언트가 모르는 것을 보내도 죽지
않아야 합니다.

## battle — 춥채팅 전투 중계

[춥채팅](https://github.com/NasusFullstack/chat)에서 '배틀크루저 소환' 치트로 사람끼리
전투를 붙일 때 조작을 서로에게 넘겨줍니다.
**평소에는 아무도 접속하지 않습니다** — 치트를 친 순간에만 붙었다가 끝나면 끊습니다.

직접 연결(P2P)도 가능하지만 실사용에서 두 가지가 걸려서 서버 중계로 갑니다.

| | 직접 연결 | 서버 중계 |
|---|---|---|
| 상대에게 내 IP가 보이는가 | 보임 | **안 보임** |
| 둘 다 공유기 뒤에 있으면 | **연결 실패** | 됨 |
| 윈도우 방화벽 허용 창 | 뜸 | 안 뜸 |

지금은 중계 기능이 없고, **WebSocket이 nginx를 통과하는지** 확인하는 단계입니다
(`/battle/ws`가 받은 글을 그대로 돌려줍니다). 막혀 있다면 nginx에 두 줄이 필요합니다.

```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

## game — 웹 게임 올려두기

브라우저에서 하는 웹 게임을 `/game/` 주소로 내려준다. **게임 파일은 이 저장소에 없다**(저장소가
공개라서). 게임을 만드는 사람이 열쇠(토큰)로 서버에 직접 올리고, 서버는 영구 보존 폴더
`/data/jsserv/game`에 둔다(`/data`가 없으면 집 폴더 `~/.jsserv/game`). 그래서 게임을 고칠 때 이 저장소를
고치거나 재배포할 필요가 없고, 배포해도 지워지지 않는다.

```
GET  /game/                  게임 첫 화면
POST /game/upload            게임 통째로 바꾸기 (본문 zip, 헤더 X-Game-Token)
GET  /game/originals/index   (열쇠) 보관 중인 원본 목록
POST /game/originals         (열쇠) 원본 그림 보관 — 바뀐 것만 올림, 옛 판은 _history 에 누적
```

게임에는 용량을 줄인 그림을 올리고 원본은 `/data/jsserv/game_originals`에 따로 쌓는다(공개 안 함).
그림 주소에 `?v=지문`이 붙으면 7일 캐시한다(내용이 바뀌면 지문이 바뀌어 새로 받음).

코드에는 열쇠의 SHA-256 지문만 있다. 열쇠를 바꾸려면 환경 변수 `JSSERV_GAME_TOKEN_SHA256`.

pip install -r requirements.txt
